# GlobeTrotter

Personalized multi-city travel planning platform.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript / JSX
- React Router
- TanStack Query
- Tailwind CSS

### Backend
- Python 3.12
- Django
- Django REST Framework
- JWT Authentication
- Django ORM

### Database
- PostgreSQL
- Neon

## Architecture

React → Django REST API → PostgreSQL

## Project Structure

- `frontend/` - React application
- `backend/` - Django REST API
- `docs/` - architecture and technical documentation
